# AI usage

ETHGlobal asks teams to say where and how AI tools were used. This file is that record. Commit authorship is the human author's; no AI tool is listed as an author or co-author.

## Tools

- **Claude (Anthropic), through Claude Code**, in the terminal, working in this repository under the author's direction. It wrote most of the code and documentation listed below. The author set the goals, reviewed the work, made the decisions (scope, what to publish, what not to deploy) and approved each milestone.
- **An image generator** for the logo and the cover. The prompts are in [assets/branding/](assets/branding/) next to the images.

## What was written with AI assistance

The commits up to `ee36461` (the executor `src/FlashArbExecutor.sol`, its first tests, the fork test, the gas snapshot and the first README) were in the repository before the sessions recorded here. Everything published after that commit was written with Claude Code:

| CI and docs | `.github/workflows/test.yml`, `README.md`, `SECURITY_NOTES.md`, `FEEDBACK.md`, `CLAUDE.md` |

The npm lockfiles are generated by npm, not written by hand or by AI.

## How the work was checked

Every change was run before it was committed: `forge test` (unit, fuzz, invariant, a Unichain fork run), the Huff differential tests against the Solidity reference, the bot's unit tests and an end-to-end test on a real local chain, and the dashboard build. Trades in the demo were checked against their receipts: quoted and realized profit, gas, and claim balances read from chain.

## Spec and planning artifacts

The agent worked from a written plan and kept a progress log. Both are published unchanged in [ai/](ai/):

- `execution-plan-1.md` and `execution-plan-2.md`: the staged plan the agent followed, split in two files at the line between its rules (§0–§4) and its stages to keep each commit reviewable. Read them in order.
- `progress-log.md`: the agent's log of each stage, with the evidence it recorded.

`CLAUDE.md` holds the standing instructions for coding agents in this repository.
